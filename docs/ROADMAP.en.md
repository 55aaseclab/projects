## Proposed · Shared project and team plans

The current task updates requirements only. The following delivery sequence is planned; no implementation, release date or completed acceptance is implied.

1. Define the project baseline, four team baselines and personal-branch contracts, ownership and explicit baseline adoption while preserving current project, work-item and reference contracts.
2. Add signed-user personal branches with structured PRD and roadmap editing, safe submissions, comparisons and manager acceptance into the parent branch.
3. Persist immutable planning history; reject stale reviews and recover genuine conflicts through explicit recorded decisions and resubmission. Preserve rejection/withdrawal history and execution facts.
4. Reuse the native Projects interface for branch selection, PRD, roadmap, changes and history; keep work views and Home navigation available in both languages.
5. Verify ownership, grants, hierarchy, conflict handling, persistence, retries and browser behavior using synthetic data. Publish the owning app revision before Praxis pins and deploys it.

Existing working records are never seeded or rewritten by maintenance. Live business-client and physical-phone evidence is recorded separately from source and synthetic checks.
